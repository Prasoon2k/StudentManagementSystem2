
# Student Management System

A simple Java-based Student Management System using **ArrayList**.

## 📌 Project Description

This project is a console-based application developed using Java.
It allows users to manage student records efficiently.

Each student contains:

- Student ID
- Student Name
- Marks

## 🚀 Features

- Add N number of students
- Display all students
- Search student by ID
- Delete student by ID
- Update student details
- Calculate average marks
- Find student with highest marks
- Exit the application

## 🛠️ Technologies Used

- Java

- Scanner
- Object-Oriented Programming
